# Portfolio de Francisco Yariel Rodríguez Alfonso

Portfolio personal de un desarrollador multiplataforma y móvil de Santa Úrsula, Tenerife. Presenta proyectos de aplicaciones web, móviles y de escritorio, además de su experiencia y tecnologías.

**Sitio:** [franciscorodalf.github.io/portfolio](https://franciscorodalf.github.io/portfolio/)

## Perfil

- Formación en Desarrollo de Aplicaciones Multiplataforma (DAM), Tenerife, 2024–2026.
- Erasmus en Bowwe, Polonia, en 2025: trabajo en embudos de conversión web, integraciones y soporte técnico full-stack.
- Experiencia previa en redes, telecomunicaciones y soporte de sistemas.

## Tecnologías

Java, Spring Boot, TypeScript, JavaScript, SQL (MySQL y PostgreSQL), React Native, Expo, Flutter, HTML, CSS, PHP, Python, C#, Unity, Git y GitHub.

## Proyectos

### Hermnet

Proyecto final de DAM: mensajería instantánea descentralizada con cifrado de extremo a extremo y un servidor que solo gestiona mensajes cifrados. El cifrado combina AES-256-GCM y RSA-OAEP-SHA256.

**Tecnologías:** React Native, Expo, TypeScript, Spring Boot, PostgreSQL, Odoo 17 y SQLite.
[Sitio oficial](https://hermnet.github.io/Hermnet-Web/) · [Repositorio](https://github.com/Hermnet/Hermnet)

### AURA

Tienda de streetwear con asistente de compra basado en IA y panel de administración para gestionar inventario y proveedores.

**Tecnologías:** Next.js, Supabase y Groq.
[Demo](https://tiendawithia.vercel.app/) · [Repositorio](https://github.com/franciscorodalf/Tienda-IA)

### Really

Aplicación móvil que introduce un periodo de espera antes de una compra impulsiva y permite destinar el importe a una meta de ahorro.

**Tecnologías:** React Native, Expo y Firebase.
[Repositorio](https://github.com/franciscorodalf/Really)

### SafeInvestor

Aplicación web para registrar ingresos y gastos, planificar presupuestos y seguir metas de ahorro. Incluye exportación a PDF y CSV y soporte como PWA.

**Tecnologías:** Spring Boot y PostgreSQL.
[Demo](https://safeinvestor.onrender.com/) · [Repositorio](https://github.com/franciscorodalf/SafeInvestor)

### PowerMine

Juego de lógica inspirado en Buscaminas, con trampas, habilidades y progresión entre partidas.

**Tecnologías:** Java e interfaz gráfica.
[Repositorio](https://github.com/franciscorodalf/PowerMine)

### Pick-A-Ball

Juego desarrollado en Unity a partir de Roll-A-Ball, ampliado con un enemigo que persigue al jugador mediante navegación NavMesh.

**Tecnologías:** C# y Unity.
[Repositorio](https://github.com/franciscorodalf/Pick-A-Ball)

## Sobre este sitio

Sitio estático hecho con HTML, CSS y JavaScript, sin frameworks, dependencias ni proceso de compilación. Incluye versiones en español e inglés, detalles interactivos de los proyectos y un formulario que prepara un mensaje en el cliente de correo del visitante.

## Desarrollo local

No es necesario instalar dependencias. Desde la carpeta del proyecto, ejecuta:

```bash
python -m http.server 8000
```

Después, abre [http://localhost:8000](http://localhost:8000).
