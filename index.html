01 · Proyecto estrella

Hermnet

El servidor transporta los mensajes. El servidor no puede leerlos.

Mensajería instantánea descentralizada con servidor ciego zero-knowledge y cifrado de extremo a extremo, construida como proyecto final de DAM.

  • Cifrado híbrido E2EE: AES-256-GCM para el mensaje y RSA-OAEP-SHA256 para encapsular la clave.
  • Servidor zero-knowledge: Spring Boot solo maneja payloads cifrados opacos en un buzón temporal.
  • Identidad soberana: el ID de usuario (HNET-…) se deriva de la clave pública del propio dispositivo.

React Native · Expo · TypeScript · Spring Boot · PostgreSQL · Odoo 17 · SQLite

02

Tienda-IA

Aplicación web para explorar flujos de compra e interfaces de tienda asistidos por IA. TypeScript · React · Vercel.

Demo ↗Código

El problema

Las tiendas online enseñan catálogos, no respuestas. Buscar un producto concreto obliga a filtrar a mano hasta dar con él.

Cómo lo resolví

Interfaz de tienda en React y TypeScript donde la búsqueda asistida interpreta lo que pide el usuario y reduce el catálogo a lo relevante. Desplegada en Vercel.

Lo que aprendí

A separar la capa de datos de la capa de conversación: el catálogo manda, la IA solo ordena y explica.

03

Really

App móvil que frena las compras impulsivas con un temporizador de espera obligatoria y lo convierte en ahorro consciente. React Native · Expo · Firebase.

Código

El problema

La compra impulsiva se decide en segundos y se lamenta durante meses. Las apps de ahorro llegan tarde: registran el gasto ya hecho.

Cómo lo resolví

App móvil en React Native y Expo que intercepta el momento previo: se registra el deseo, arranca un temporizador de espera obligatoria y, si al vencer ya no interesa, el importe pasa a una meta de ahorro. Datos en Firebase.

Lo que aprendí

Que el diseño de producto puede ser una restricción deliberada: la fricción, bien colocada, es la función.

04

SafeInvestor

Gestor financiero de ingresos, gastos y metas de ahorro con una interfaz de escritorio práctica. Java · SQL.

Código

El problema

Llevar ingresos, gastos y metas de ahorro en una hoja de cálculo funciona hasta que dejas de actualizarla.

Cómo lo resolví

Aplicación de escritorio en Java con persistencia en SQL: registro de movimientos, categorías y metas con su progreso, pensada para abrirse y usarse en menos de un minuto.

Lo que aprendí

A modelar el dominio antes que la pantalla, y a que un esquema SQL bien planteado ahorra la mitad del código de la interfaz.

PowerMine

Reinterpretación del Buscaminas con trampas, habilidades y progresión: reglas reescritas, no copiadas. Java · GUI.

Código

El problema

Clonar el Buscaminas no enseña nada. El reto era conservar su tensión y cambiar sus reglas.

Cómo lo resolví

Versión en Java con interfaz gráfica propia donde entran trampas, habilidades activables y progresión entre partidas, sobre el mismo tablero de deducción.
